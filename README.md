# Grid World – Reinforcement Learning

Projekt z przedmiotu „Uczenie się ze wzmocnieniem”.

## Temat
Agent uczący się optymalnej nawigacji w środowisku Grid World z ograniczonym zasobem energii.

## Założenia
Agent porusza się po siatce, unika przeszkód i pułapek, zarządza energią oraz stara się dotrzeć do celu. Planowany algorytm: tablicowy Q-learning.

## Struktura
- `src/` – kod środowiska i agentów (do uzupełnienia)
- `experiments/` – skrypty eksperymentalne (do uzupełnienia)
- `report/` – raport projektowy LaTeX
- `results/` – wyniki eksperymentów
- `report.tex`, `article_style.tex` – źródła raportu

## Raport
Przenieś pliki `report.tex` i `article_style.tex` do katalogu `report/` (albo kompiluj je z katalogu głównego). Uzupełnij dane studenta i link do repozytorium przed oddaniem.

## Planowane rozszerzenia
- implementacja środowiska Grid World,
- agent losowy jako baseline,
- agent Q-learning,
- porównanie na kilku mapach i analiza wyników.
